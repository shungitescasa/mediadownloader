for developers

All endpoints are relative to this instance. Responses from /queue, /stop and errors are JSON in the following shape: 

{
  "status_code": 202,
  "message": "queued",
  "data": null
}

A task id is a 64-character lowercase hex string (sha256 of type and url). Task statuses: pending, downloading, done, failed. Finished tasks expire after the queue TTL configured by the instance.

add links to the queue

POST /queue

Request type: multipart/form-data

field type description example
url string http(s) link. May be repeated, or hold several links separated by newlines or commas. https://www.youtube.com/watch?v=S4WuVmq5osc,https://youtu.be/bsdPeW-dzGM
type string one of video, audio, meta. Defaults to video. audio

Returns 202 with data as an array of tasks (id, url, type, status, created_at, expires_at). Errors: 400 invalid form, url or type, 429 queue is full. 

curl -X POST {{.Origin}}/queue \
  -F "url=https://www.youtube.com/watch?v=4X6UqQDmjBk" \
  -F "type=audio"

track a task

GET /track

Request type: query. Responds with a Server-Sent Events stream; an event is sent on connect and on every status change, and the stream closes once the task is done or failed.

field type description
id string task id returned by /queue.

Each event is data: {"id":"...","url":"...","status":"downloading"} . Errors: 400 invalid id, 404 not found. 

curl -N "{{.Origin}}/track?id=TASK_ID"

download a finished file

GET /download

Request type: query. Returns the file as an attachment.

field type description
id string id of a task with status done.

Errors: 400 invalid id, 404 not found, 409 not ready yet, 410 download failed. 

curl -OJ "{{.Origin}}/download?id=TASK_ID"

stop and remove a task

DELETE /stop

Request type: query. Cancels the task if it is running and removes it from the queue.

field type description
id string task id returned by /queue.

Returns 200 with message stopped. Errors: 400 invalid id, 404 not found. 

curl -X DELETE "{{.Origin}}/stop?id=TASK_ID"
